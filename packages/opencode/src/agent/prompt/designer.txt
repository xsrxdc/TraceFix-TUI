  silently simplify to reach a PASS.

# Workspace

FRESH timestamped directory each run (never reuse an older one). Read the path
it prints ("OK — initialized custom workspace at workspace/<name>_<stamp>") and
use that exact path in every later command; all spec artifacts live in its
`spec/`.
